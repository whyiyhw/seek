# Vision：从编程助手到本地计算机智能终端

> 本文是 seek 的长期愿景文档，不是具体版本路线图。它描述未来 3–5 年的北向星方向，帮助新功能决策对齐——**做正确的事，而不仅是把事情做对**。

## 1. 核心主张

seek 的长期愿景是从编程助手演化为**本地计算机智能终端**——一个能够自主感知、推理并操作系统原生环境的 AI 代理。

当前 seek 是"盲人代理"：它通过结构化文本（代码、文件、命令输出）间接理解环境，能力再强也受限于感知带宽。**视觉能力是打破这一瓶颈的关键缺失拼图。**

## 2. 三层架构

```
┌──────────────────────────────────────────────┐
│              CLI 层（seek 核心）               │
│  推理 · 规划 · 决策 · 对话 · 审计 / Memory    │
├──────────────────────────────────────────────┤
│         MCP 标准化桥接（协议层）               │
│   工具发现 · 权限路由 · 流传输 · 事件订阅      │
├──────────────────────────────────────────────┤
│         系统原生应用层（能力层）               │
│  视觉采集 · OS 钩子 · 硬件接口 · 后台守护进程  │
└──────────────────────────────────────────────┘
```

### 2.1 CLI 层——稳定核心

CLI 不是过渡方案，而是**智能终端的中枢神经**。它在所有操作系统上存在，穿透容器、SSH、无头环境，以最少依赖提供确定性交互。无论上层能力如何增强，CLI 维护的是交互的**确定性**与**可审计性**——这两点是任何自治代理不敢放弃的底牌。

### 2.2 MCP 桥接层——通用协议

MCP 将一切资源抽象为标准协议：文件系统、浏览器、数据库、设计工具、系统服务、传感器、视觉流。工具可发现、能力可插拔、权限可路由。seek 当前的 `internal/tools/mcptool/bridge.go` 已经验证了这一路径。

### 2.3 系统原生应用层——能力载体

系统应用解决 CLI 做不到的事：

- **视觉采集**：截屏/录屏权限（需要 macOS Screen Recording、Windows 图形捕获等 entitlements）
- **深层 OS 钩子**：辅助功能 API（Accessibility）读取 UI 元素树、系统偏好读写、硬件监控
- **持久化守护**：后台事件监听、定时任务、通知推送

系统应用与 CLI 层通过 MCP 通信，不耦合。CLI 层可独立演进；系统应用可替换（例如桌面版 vs 手机遥控版）。

## 3. 视觉闭环：智能体从"盲"到"看"

```
看见（屏幕/UI状态） → 理解（LLM推理） → 规划（Plan Mode）
       ↓                                      ↓
   验证（视觉反馈） ← 执行（CLI + GUI 混合）
```

视觉不是锦上添花，它补全了自主操作的最后一环。没有视觉的代理只能操作"已经被文本化了的东西"（代码、API、配置文件）；有了视觉，它可以：

- 看弹窗是什么 → 决定点哪个按钮
- 看配置面板 → 找到开关位置 → 操作
- 看进度条 → 判断是否卡住 → 干预
- 看设计稿 → 理解布局 → 生成代码

## 4. 这条路的起点

seek 现在的架构已经为这一愿景准备了基础：

| 现有能力 | 对应愿景中的作用 |
|---------|----------------|
| 工具系统（`internal/tools/`） | 三层中 CLI 层的可扩展骨架，每加一个工具=多一种资源类型 |
| MCP 桥接（`internal/tools/mcptool/`） | 标准化协议层已验证，系统应用只需暴露 MCP Server |
| 权限模型（两轴四象限） | 视觉+系统级操作的安全策略容器 |
| Plan Mode（`internal/tools/plan/`） | 多步视觉驱动操作的编排引擎 |
| Memory 层（L/M/S） | 长期记忆 + 教训记录，让代理"认识"这台机器的特征 |

## 5. 不是路线图，是方向

本文列出的是北向星，不是 v4/v5 的交付承诺。具体优先级取决于：

- 底层模型何时具备可靠的视觉理解能力（DeepSeek Vision 或替代方案）
- 操作系统的权限边界如何演进（sandbox、TCC、entitlements）
- 用户社区的实际需求排序

但方向不变：**CLI 底层 + MCP 协议 + 系统能力层 + 视觉闭环 = 本地计算机智能终端**。
