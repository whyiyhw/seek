### 排除表纪律只写在「存量复查」侧就没有闸——新增脚本照样加一行带借口的排除臂
- **Saw**: `selftest.sh` 头注释有「排除理由会腐化，默认倾向重判」（c_kwiajf），但 c_gqo32q 打开时已有两条过时臂：`web-stream-manual` 理由「移出前先补 exit 3」，`web-md-manual` 有无头分支却未进判据；此后 c_5m3fm6/c_txz6vz/c_ni7mzw 三张 W5 卡撞墙。
- **Why**: 纪律只作用于已有条目（旧理由可疑），对新作者无约束——可加一行 `xxx-manual) echo "交互阻塞" ;;`；缺口在增量。
- **Fix**: c_gqo32q 在头注释补「新增门禁」三条：①新增 `*-manual.sh` 默认不进排除表；②「有无头分支但缺非 TTY 退路」不合法（`[ ! -t 0 ] → exit 3` 三行可修）；③排除条目须写结构性理由+依据；「补 X 后可移出」＝自证过时，当场重判。
- **Lesson**: 写纪律先问「约束存量还是增量」——描述既有状态的文档（排除理由/弃用清单/白名单）只管存量；要挡下一次须写默认值与举证责任——「记得复查」不产生闸。
