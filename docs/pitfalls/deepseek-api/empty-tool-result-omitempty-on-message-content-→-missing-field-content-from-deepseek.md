### Empty tool result + `omitempty` on `Message.Content` → "missing field `content`" from DeepSeek
- **Saw**: a session crashed with `deepseek api error: invalid_request_error: Failed to deserialize the JSON body into the target type: messages[15]: missing field 'content'` after `memory_observe(...) → 0 bytes`.
- **Why**: `memorytool.Observe.Execute` returns `("", nil)` (async enqueue, sync success), but `Message.Content`'s `json:"content,omitempty"` drops the key for `Content=""` — DeepSeek requires it on tool-role messages. Removing `omitempty` breaks assistant messages carrying only `tool_calls`.
- **Fix**: `pkg/agent.buildToolResultMsg` centralises tool-result creation, substituting `"(no output)"` on empty + nil error (errors win via `tool error: ...`); `session.Session.Repair`'s `backfillEmptyToolContent` resumes pre-guard sessions; pins `TestBuildToolResultMsg`, `TestAgent_EmptyToolResult_WirePresent`, `TestRepair_BackfillsEmptyToolContent`.
- **Lesson**: `omitempty` on a shared struct field is a hidden contract risk — optional in one role, mandatory in another; check what the next serialisation does with a silent-success empty string.
- **Refs**: `pkg/agent/agent.go:buildToolResultMsg`, `internal/session/session.go:backfillEmptyToolContent`, `internal/tools/memorytool/observe.go`
