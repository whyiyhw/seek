### 核价日期搬进台账后，文档里的同款日期戳变成过期副本——判据是「哪份文件是唯一权威」，不是「哪份文件被改过」
- **Saw**: 台账落地（c_ldu44u）把 pricing.go 注释里 7 处 checked/verified 日期收进 `ledger.go`，`go test -race ./...` 全绿、自测 9/9；但 README.md:86 / README.zh.md:84 脚注仍写「verified 2026-11-14 … 见 pricing.go」，而台账里 DeepSeek 两卡已 bump 到 2026-11-20，另漏 pricing_test.go:274 的 `checked 2026-11-12`。
