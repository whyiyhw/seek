### Provider model-alias sunset dates silently orphan string-literal references
- **Saw**: a week after DeepSeek removed `deepseek-chat`/`deepseek-reasoner` (2026-07-24), the TUI picker still offered "DeepSeek V4-Flash" under dead id `deepseek-chat` (404); legacy constants, rate-card and budget entries still live.
- **Why**: alias sunsets are announced in provider docs, not code; deleting the constant catches references at compile time, but string literals (picker entries, httptest fixtures, `session.New` args) compile forever — the sweep missed `pricing.go:89` (`standardRates[deepseek.ModelChat]`), surfaced only via `go vet`.
- **Fix**: sweep removed `ModelChat`/`ModelReasoner` constants, rate-card + budget context-limit entries, picker entry (`deepseek-chat` → `deepseek-v4-flash`), test fixtures; pricing fallback → `ModelV4Flash`; old alias-named sessions degrade to unknown-model handling, not load failures.
- **Lesson**: on an alias sunset, same-day grep for BOTH constant names and raw wire strings — picker/status-bar/CLI help are the last places you'd look; re-verify pricing/context-limit fallbacks.
- **Refs**: `pkg/deepseek/types.go`, `internal/tui/commands.go:knownModelsForProvider`, `internal/pricing/pricing.go:PricingFor`, `internal/budget/budget.go:contextLimits`
