### DeepSeek pricing pages are single-currency per language — cross-currency diffs flag phantom rate changes
- **Saw**: feature-deepseek-app-api.md §0 (2026-11-13) reported flash "repriced" to ¥2/M peak-miss vs pricing.go's $0.30 — the EN page still listed $0.30; no flash change, only deepseek-v4-pro regaining its own row
- **Why**: EN lists USD only, ZH CNY only. DeepSeek's implied rate is ~6.67 CNY/USD (¥2=$0.30), pricing.go's GLM row assumes 7.0 — CNY vs 7.0-converted USD manufactures a ~5% "change"
- **Fix**: verified 2026-11-14 against BOTH pages; flash unchanged (comment re-dated), deepseek-v4-pro got its own registry entry ($1.32/$0.044/$3.96 peak — it had silently left the Flash-routing legacy list, whose fallback undercharges ~4×), searchPerCallUSD → natively-listed $0.75/1K
- **Lesson**: diff like-for-like currency (or convert at the page's implied rate) before declaring a rate change. Routing is as volatile as prices: "v4-pro is Flash-routed" (2026-09-10) held two months then reversed — re-read the legacy-id note on every pricing check
