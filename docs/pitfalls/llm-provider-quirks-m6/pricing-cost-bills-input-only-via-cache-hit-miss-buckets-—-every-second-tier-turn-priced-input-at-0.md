### pricing.Cost bills input ONLY via cache-hit/miss buckets — every second-tier turn priced input at $0
- **Saw**: GLM money stats only counted output — input $0 every turn, `cache hit 0/0 ratio n/a` — and the earlier smoke conclusion "no cache metadata comes back" was unfalsifiable.
- **Why**: three links dropped it — `streamUsage` didn't declare `prompt_tokens_details` (json skipped `cached_tokens`), `llm.TurnDone` carried no cache field, `runTurnLLM` synthesised `deepseek.Usage` with hit/miss zero — and `pricing.Cost` prices input ONLY through those buckets (`PromptTokens` is never read), so input cost was structurally $0.
- **Fix**: `TurnDone.CachedInputTokens` + `streamUsage.prompt_tokens_details.cached_tokens` + `runTurnLLM` splitting input into hit/miss (clamped), plus `glm-5.3`'s `NoOffPeakDiscount` card; fake-wire check (prompt 1000 / cached 600 / completion 12): `est. cost $0.0007`, jsonl `prompt_cache_hit_tokens: 600 / miss: 400`.
- **Lesson**: for "cost shows $0", read what the billing function consumes, not whether the call happened; a wire type that doesn't declare a field makes "server didn't send it" and "client dropped it" observationally identical — verify wire contracts by dumping the raw stream.
