### Capability grants were installed only when the process LAUNCHED on OpenCode Go — a mid-session switch onto an opencode id silently lost vision

- **Saw**: `seek acp` with no provider pin (auto-detect → deepseek); host sent `session/set_config_option("opencode:hy4-flash-free")` + `session/prompt` with a red/blue PNG → `我看不到这张图——当前模型不支持图片输入` (`switchModelNote` branch), image never reached the gateway. Same run with `SEEK_ACP_PROVIDER=opencode` at launch answered 红色/蓝色; `modelcap.Vision("hy4-flash-free")` false in group A, true in B — only the launch lane differed.
- **Why**: `cmd/seek/main.go` gated the catalogue bootstrap on `provLabel == "OpenCode"`, and `Snapshot.Install()` is the ONLY writer of the gateway's `modalities.input` into `modelcap.SetVision`/`SetFiles`. `modelcap`'s static table covers each lane's *defaults* only, denying unknown ids — catalogue-only ids (hy4-flash-free, hungerg-free, longcat-2.5, …) are vision-capable purely by grant. The answer rode a startup accident, not the credential. Same gate: `openCatalogRows()` nil → `acpModelMenu` fell back to the compiled list, catalogue ids never in the dropdown.
- **Fix**: `initCatalogueAtStartup(cfg)` — seed iff `laneHasCredential(cfg, "opencode")` (key in env/config, or a stored `seek auth opencode` login), never per launch lane; cache first, refresh goroutine unchanged, no credential → nothing installed (no uncallable menus, no HTTP). NOT lazy on lane switch: a cache read + refresh goroutine on `SetConfigOption`'s path, and the TUI `/model` picker (switches *within* a lane) would still miss it. Commit: `git log -- cmd/seek/catalogue_gate_test.go`.
- **Lesson**: a grant is a fact about the MODEL and GATEWAY, not the process's startup state — gate on the durable fact (credential/machine), not the ephemeral one (auto-detected lane). Tell: both symptoms were "surface fell back to the compiled baseline" = what the fallback *means* ("no such lane here"), so a wrong gate reads as design, not bug. Verified 2026-11-25 by ACP direct-drive (card c_nfeloo): A-group probe flips from `image dropped with switch-model note` to `image sent to model`, B unchanged.
