### A self-skipping test suite makes a missing CI secret look like a pass
- **Saw**: `pkg/agent/cache_e2e_test.go` skips without `DEEPSEEK_API_KEY` (correct for `go test ./...`), but in a credentialed CI job it's a trap: a deleted/renamed/misconfigured secret makes every real-API test skip, the job exits 0, the safety net gone, the dashboard green.
- **Why**: "all tests skipped" and "all tests passed" share an exit code — a self-skipping suite asserts nothing unless proven it ran.
- **Fix**: `.github/workflows/e2e.yml`, separate from `ci.yml` (different credential/trigger lifecycles; `ci.yml` stays keyless/forkable/green). An unconditional preflight fails with `::error::` on an empty key; a `grep` for a literal `--- PASS:` line separates ran-and-passed from skipped-everything. The untrusted-PR skip keys on the PR author (`pull_request.user.login`), not `github.actor` — a maintainer re-running a Dependabot PR makes the actor human while the PR stays keyless.
- **Lesson**: any gate whose subject can skip itself needs a positive liveness assertion — if "silently does nothing" looks like success, the check is decorative.
- **Refs**: `.github/workflows/e2e.yml`, `pkg/agent/cache_e2e_test.go`, dsh `.agents/notes/implemented/testing/2026-06-19-real-api-e2e-ci.md`
