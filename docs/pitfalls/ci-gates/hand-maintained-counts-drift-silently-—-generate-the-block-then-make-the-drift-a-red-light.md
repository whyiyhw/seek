### Hand-maintained counts drift silently — generate the block, then make the drift a red light
- **Saw**: this file carried three hand-written derivations of its own body (live total, Per-section table, four-bucket rollup); measured 2026-11-20 the table summed 264 vs 268 real, the Total row said 255, the rollup 34/35/43/143 — three stale generations of one number.
- **Why**: a derived number is a second source of truth kept in step only by the last editor remembering; partial updates are worse than none — two contradictory numbers, neither detectably wrong, and "review by eye" had no carrier.
- **Fix**: `scripts/pitfalls-count.sh` regenerates the header block between two HTML-comment markers from the body (`--write`) and diffs it back (`--check`), so drift is a non-zero exit naming the section; warns on same-prefix sections; wired into `ci.yml` doc-budgets + `scripts/selftest.sh`. Marker matching is whole-line/single-occurrence (a prose mention once made `--write` duplicate the block).
- **Lesson**: any number summarising a file must be computed from it where the edit happens; the same number written twice in one file is a scheduled contradiction, not redundancy.
