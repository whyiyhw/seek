### 空态镜头的侧栏只有 117px——截图落在 .15s 宽度过渡的半途

- **Saw**: 审查矩阵的 01–04（聊天空态）里侧栏只有 117–167px，标题和搜索框全被截断；同一轮的其它镜头侧栏是完整的 260px。宽度每次跑都不一样。
- **Why**: `setViewport` 先 `setSideCollapsed(false)` 就返回，Phase A 紧接着 `Page.captureScreenshot`。侧栏宽度带 `transition: width .15s`，截图落在过渡中途——后面的面板镜头导航耗时够长，过渡早走完了，所以只有空态镜头中招。
- **Fix**: `setViewport` 等侧栏宽度连续两次读数相同再返回（c_zib76h）。不写死目标宽度（各分支 260/280、轨 44/56 都有），先空等一帧再读，免得过渡还没起步就被判成稳定。
- **Lesson**: 有 CSS 过渡的属性，截图/断言前要等它落定；「等固定毫秒」在慢机器上仍会漏，等「读数不再变」才与时长无关。镜头之间宽度不一致、且每次不同，是「拍到过渡态」的典型指纹。
- **Refs**: `scripts/web-page-review-headless.mjs`（`setViewport`）、`internal/controlplane/webfrontend.html`（`#side` 的 `transition: width .15s`）
