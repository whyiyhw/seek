### 退役一套视图时连带删掉别处依赖的规则——32 张面板镜头全破，三轮验证没人看

- **Saw**: W6-5 落地后，打开任一面板（记忆/统计/后台/设置/审计），空态 Hero、「已到末尾」和输入卡片都留在页面上，和面板内容叠在一起；会话头还压在面板首行上。全绿的无头验收、验证会话、以及一次人工复核都没发现。
- **Why**: W6-5 主提交删只读浏览器时，把 `body.browsing #list, body.browsing form { display: none; }` 一并删了——它不属于只读浏览器，是「面板打开时聊天面让位」的互斥规则。唯一守着它的断言在 web-subagents 族，而 W6 各卡的验收清单都没列这一族；page-review 的 32 张图里有 10 张面板镜头，但大家的眼睛只看聊天视图那两张。
- **Fix**: 规则找回并补齐 W6-4/5 新增的件（`#hist`、`#hist-foot`、`#composer-meta`；面板按内容态处理：会话头回文档流、清历史游标），Go 侧加钉（c_mo7quv 返工）。
- **Lesson**: 「替换不是叠加」删旧规则前，先 grep 这条选择器还被谁的行为依赖，并跑所有碰这块 DOM 的无头族——不只是卡面点名的几族。截图矩阵出了图不等于有人看：验收要写明哪些镜头必须人眼过，面板视图至少一张。
