### 退役一套视图时连带删掉别处依赖的规则——32 张面板镜头全破，三轮验证没人看

- **Saw**: W6-5 后打开任一面板（记忆/统计/后台/设置/审计），空态 Hero、「已到末尾」、输入卡片都叠在面板内容上，会话头还压在面板首行。全绿的无头验收、验证会话、一次人工复核都没发现。
- **Why**: W6-5 主提交删只读浏览器时，把 `body.browsing #list, body.browsing form { display: none; }` 一并删了——它不属于只读浏览器，是「面板打开时聊天面让位」的互斥规则。唯一守它的断言在 web-subagents 族，W6 各卡验收清单都没列；page-review 32 张图有 10 张面板镜头，但大家只看聊天视图那两张。
- **Fix**: 规则找回并补齐 W6-4/5 新增件（`#hist`、`#hist-foot`、`#composer-meta`；面板按内容态：会话头回文档流、清历史游标），Go 侧加钉（c_mo7quv）。
- **Lesson**: 「替换不是叠加」——删旧规则前先 grep 这条选择器还被谁依赖，跑所有碰这块 DOM 的无头族。截图出图 ≠ 有人看：验收要写明哪些镜头人眼过，面板至少一张。
