### 空态会话头横穿侧栏——绝对定位没给主栏定位，空态类又只看实时列表

- **Saw**: 空态与「点开历史会话」两种状态下，会话头从页面最左端起、横穿 280px 侧栏盖住品牌行（W6-4 起就有，W6-5 的历史视图把它带进了更常见的场景）；手机宽下压住 44px 图标轨，历史首条消息也被会话头盖住第一行。
- **Why**: 两层。① `body.chat-empty-on #conv-head { position: absolute; left: 0; right: 0 }` 想贴主栏顶，但 `#center` 没定位，包含块落到页面，left/right 就是页面两端。② `chat-empty-on` 只按实时 `#list` 判定；W6-5 看历史时实时列表空着，这个类还挂着，空态布局（会话头绝对化、内容居中、composer 上浮 64px）整套跟进历史视图。
- **Fix**: 空态给 `#center` 定位（只在非看历史态）；`body.viewing.chat-empty-on` 下会话头回文档流、内容顶对齐、composer 落回底部（c_mo7quv 返工）。四态 × 两视口几何探针 + 32 张重拍验证。
- **Lesson**: 绝对定位的元素要问一句「包含块是谁」——想让它在某一栏里贴边，那一栏就得定位。按单个容器判出来的状态类，新增另一种视图时要显式排除：视图变多了，「列表为空」不再等于「页面是空态」。
