### 行内操作组靠底色遮字——行一有悬停层，补丁就显形

- **Saw**: W6-1 给会话行加了悬停层之后，鼠标悬停的行上出现一块异色补丁（亮色偏浅、暗色偏深），压在成本数字上；32 张截图矩阵、人眼过目、链验证三轮都没拍到。
- **Why**: `.sess-acts` 绝对定位浮在行文字之上，靠 `background: var(--seek-panel)` 盖住底下的字避免叠字。行底透明时补丁与行同色、看不见；`.sess-row:hover` 把行底换成半透明的 `--seek-hover` 之后补丁色就跟不上——而且半透明叠半透明，照抄悬停 token 还会再深一档。截图矩阵没有鼠标悬停镜头，`:hover` 态从头到尾没人看过。
- **Fix**: 操作组去掉底色；悬停/聚焦时让行自己让位（`.sess-row:hover, .sess-row:focus-within { padding-right: 68px }`，改名态还原 12px）。让位落在行上而不是 `.t1/.t2` 上，W6-2 把行改成单行后照样成立。`TestWeb_PageVisualBase` ⑤ 钉住（c_pozbmd 返工）。
- **Lesson**: 「靠底色盖字」的浮层只在底色唯一时成立——给容器加悬停/选中/归档任何一层，补丁就显形。让位要用布局（留白）解决，不要用遮盖。另外 `:hover` 态必须进验收证据：无头截图里用 CDP `Input.dispatchMouseEvent` 真移鼠标；页面 CSP 拦动态 `<style>`，验证候选样式要走 CSSOM（`el.style.x = …`）。
