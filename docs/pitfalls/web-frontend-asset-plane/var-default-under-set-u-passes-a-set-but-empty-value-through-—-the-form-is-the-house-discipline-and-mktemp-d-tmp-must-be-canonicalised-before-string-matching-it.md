### `${VAR-default}` under set -u passes a set-but-EMPTY value through — the `:-` form is the house discipline; and mktemp'd $tmp must be canonicalised before string-matching it
- **Saw** (c_w3vhcm, 2026-11-18): two self-test bugs. (a) `case_filter=${1-}` kept an empty arg empty (`ablate.sh '' ''` → binary="" not the default). (b) path normalisation `sed "s|$tmp|...|"` never matched: macOS `TMPDIR` ends in `/` (mktemp returns `//`), `/var` is a symlink to `/private/var`, and the script-under-test's paths round-tripped `cd`+`pwd`.
- **Why**: `${VAR-default}` only substitutes on UNSET; empty-but-set sails through (`:-` substitutes on both). String-matching paths compares the STRING, not the file — mktemp's return is not canonical on macOS.
- **Fix**: `eval/ablate.sh` uses `:-` throughout; `scripts/eval-ablate-test.sh` canonicalises `tmp=$(cd "$tmp" && pwd)` right after mktemp and asserts non-empty output (first revision's malformed sed normalised both sides to empty — two empty files `cmp`'d green).
- **Lesson**: "compare two outputs" tests need a negative control (inject a one-char difference, watch it go red) and a non-empty guard on both sides — symmetric degradation of both arms is the silent false-green mode.
- **Refs**: `eval/ablate.sh`; `scripts/eval-ablate-test.sh`; card c_w3vhcm.
