### 夹具会话的项目目录不存在——执行器拉不起子进程，整族的无头桩形同虚设

- **Saw**: 给 web-sessions 族装了桩 seek、断言「正文被拉起」，桩日志却是空的；转录区里是 `run 失败：controlplane: exec seek: fork/exec …/bin/seek: no such file or directory`，而那个文件明明在。
- **Why**: 执行器以会话自记的项目目录为子进程的工作目录（`cmd.Dir`）；夹具会话头写死 `"cwd":"/tmp/w44-fixture"`，脚本从不创建它。目录不存在时 fork/exec 报的是 ENOENT，文案却指向可执行文件，容易误读成桩没装上。
- **Fix**: 夹具目录改到沙盒内并创建（`FIXTURE_CWD="$TMP/w44-fixture"`），路径经 `--proj` 传给无头脚本（c_mo7quv 返工）。
- **Lesson**: 凡是「子进程以某目录为 cwd」的夹具，那个目录必须真实存在。此前整族没有一条断言依赖子进程被拉起，所以坏了没人知道——桩装上后，第一条断言就该是「桩确实被调用了」。
- **Refs**: `scripts/web-sessions-manual.sh`（`FIXTURE_CWD`）、`internal/controlplane/executor.go`（`cmd.Dir = req.Dir`）
