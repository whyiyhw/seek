### `seek autopilot run` 车道从不升 pref，且 `--yolo` 没有可表达的位置——产线 subagent 的 bash 全被拒
- **Saw**: 2026-11-21（c_2aymtn）：worker 的 `edit`/`write` 过，`bash` 全拒 `permission denied: bash is gated; re-run seek with --yolo …`，`go test ./...` 跑不了。
- **Why**: `run()` 仅 `goalMode` 分支 `SetPref(PrefYolo)`（`main.go:1745-1750`）；`autopilotMode`（`:1377-1388`）留 `PrefDeny`，子代理经 `ParentPolicy.Spawn` 只降不升。`--yolo` 又放不进：flag.Parse 遇首个非 flag 参数即停，`autopilot run "g" --yolo` 把 flag 折进 goal 串；`--yolo autopilot run` 则因车道判定读 `os.Args[1]`（`:1241`）失效。
- **Fix**:（c_skczdu，2026-11-25）车道探测改读 `flag.Args()`，pref 由 `initialPreference` 解出即 Yolo，仍受 `LaneAutopilot` 闸（拒 `git push`、放 `go test`，`TestAutopilotLane_NoRemoteGuardStillDenies`）；flag 放子命令后改显式报错并点名出错 flag（`TestAutopilotInvocation`、`TestAutopilotFlagShapesE2E`）；cron 计费闸（v8 §9.5③1，c_kdblc4）原同判 `os.Args[1]=="autopilot"`，改判 `autopilotLane`（`TestAutopilotCronGate_E2EFiresOnFlagLedShape`：`SEEK_AUTOPILOT_CRON=1`+metered pin 仍拒、零请求）。
- **Lesson**: 无人车道 pref 必须车道自升；`os.Args[1]`→`flag.Args()` 非单点替换——每处 `os.Args[1]=="autopilot"` 都是一道闸（`grep 'os.Args\[1\]'` 即清单），漏一处即静默绕闸。
