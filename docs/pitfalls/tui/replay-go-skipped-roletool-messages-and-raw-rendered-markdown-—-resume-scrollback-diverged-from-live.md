### replay.go skipped RoleTool messages and raw-rendered Markdown — --resume scrollback diverged from live
- **Saw**: every `--resume`d session with tools showed no tool results, raw Markdown source instead of styled output, and spurious `▸ seek` blocks for reasoning-only turns.
- **Why**: `renderReplayHistory` unconditionally skipped `deepseek.RoleTool` (line 32: `continue`); `formatReplayAssistant` used raw `msg.Content` instead of `renderMarkdown()`, emitted `▸ seek` for any tool_calls message even when `msg.Content == ""` (live path `update_agent.go:178` gates on `m.curContent != ""`), and did not truncate args while live uses `truncateOneLine(args, 80)`.
- **Fix**: render RoleTool as `↳ name(args) → N bytes` via a cross-message `toolCallMap`; glamour Markdown via `newMarkdownRenderer()`; return `""` from `formatReplayAssistant` when `msg.Content == ""`; apply `truncateOneLine(args, 80)` to tool-call args.
- **Lesson**: "replay should mirror live" is a documented invariant — when adding a display feature to the live path (view.go + update_agent.go), update replay.go in the same commit or `--resume` silently drifts.
- **Refs**: `internal/tui/replay.go`, `internal/tui/update_agent.go:178`, `internal/tui/run.go:56`
