### Status-bar glyph-width oracle mismatch soft-wraps the frame and ghosts the welcome banner
- **Saw**: after `/model` switched to `deepseek-v4-flash-vision-exp` the pixel banner showed TWICE — the prior frame's top block where the repaint never reached.
- **Why**: lipgloss and the terminal disagree 1–2 cols on the status bar's ambiguous-width glyphs (the frame's LAST line — ☀️ U+2600+VS16, ○ U+25CB render wider on CJK-locale Windows Terminal), so the bar soft-wrapped onto 2 rows; the 10-col longer vision-exp id pushed it into the boundary band (widths 90–110; PowerShell default 100).
- **Fix**: foldStatusBar reserves a 2-col margin; RenderStatusBar draws width−2 with MaxWidth truncation; picker "(current)" moved off the `%-32s` id column; glyphs later dropped for ASCII, pinned by `TestRenderStatusBar_NeverExceedsTerminalWidth` + `TestStatusBar_NoRetiredEmojiGlyphs`.
- **Lesson**: under inline bubbletea a frame line wider than the frame is a rendering-desync bomb — the ghost surfaces at the TOP from a wrap at the BOTTOM; measure with the strictest oracle.
- **Refs**: `internal/tui/statusbar.go` (`foldStatusBar`, `RenderStatusBar`), `internal/tui/view.go` (`renderModelPicker`), Windows Terminal zh-CN after /model → vision-exp
