### lipgloss v2 background probe hangs forever when stdin is piped (Windows CONIN$)
- **Saw**: `go test ./...` on a Windows dev box hung the full 10m timeout at `TestDetectGlamourStyle_Fallback` (goroutine stuck in `syscall.ReadConsole`); `seek` launched with redirected stdin hung likewise at startup.
- **Why**: lipgloss v2's `BackgroundColor` on Windows, seeing non-tty stdin, opens `CONIN$`, raw-mods it, waits for an OSC 11 reply; the 2s timeout in `queryTerminal` cancels the reader, but `CancelReader.Cancel()` does NOT interrupt a blocked `ReadConsole` on every console host; termenv degraded gracefully — a v2 regression.
- **Fix**: gate the probe on real-terminal stdin (`isatty.IsTerminal || IsCygwinTerminal`): non-tty → assume dark, skip the query; `TestDetectGlamourStyle_NonTTYStdinSkipsQuery` swaps os.Stdin for a pipe.
- **Lesson**: a terminal-query helper that "falls back on error" is not hang-safe — check the fallback covers the no-reply case on EVERY platform, or gate the call on the precondition (tty stdin); green CI can hide platform hangs only a local full-suite run catches.
- **Refs**: `cmd/seek/main.go:detectGlamourStyle`, `charm.land/lipgloss/v2 query.go:BackgroundColor`, `internal/tui/teatest` migration notes; commit (this commit)
