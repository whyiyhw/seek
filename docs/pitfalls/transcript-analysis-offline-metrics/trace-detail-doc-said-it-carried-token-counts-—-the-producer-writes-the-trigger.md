### trace `Detail` doc said it carried token counts on a compact — the producer writes the trigger
- **Saw**: wiring compact duration into `ui-trace` (card c_x2qga6): `uitrace.Event.Detail`'s comment said "_token counts on a compact_", but `internal/tui/update_agent.go:handleCompactDone` writes `msg.trigger` (`"manual"` / `"auto"`); the tokens live in the separate `Tokens` field. A report built from the comment groups by the wrong axis.
- **Why**: the comment predated the split of `Tokens` into its own field; nothing tests a comment, and `TestTrace_CompactRowCarriesTrigger` only pins the produced value — both were individually consistent while disagreeing.
- **Fix**: corrected the comment (`internal/uitrace/uitrace.go`) and added `DurMSByEvent` so the duration axis has an aggregate slot. A field whose meaning changed keeps its wire spelling — renaming `detail` would break every existing row.
- **Lesson**: when a field's payload is split, the doc comment is part of the contract and must be edited in the same commit — a test asserts the value written, never the prose that tells the next reader how to query it.
- **Refs**: `internal/uitrace/uitrace.go` (`Event.Detail`, `Summary.DurMSByEvent`), `internal/tui/update_agent.go:handleCompactDone`, `internal/uitracecli/uitracecli.go:printSummary`
