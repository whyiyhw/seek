### Exhausted empty retries must be booked as a message — a bare assistant tail is a 400, not a self-heal
- **Saw**: `opencode:deepseek-v4.1-flash`, 11-20: `agent: model returned an empty response` 8+×, each ending the session (`/tmp/seek-acp.log` silent 51 lines).
- **Why**: exhausting `agentStreamRetries=1` hit `ErrorEvent + return`; a clean empty renders nothing, and the wire forbids an assistant with neither content nor tool_calls ("content or tool_calls must be set").
- **Fix**: on `errEmptyResponse` at exhaustion book `emptyResponseMarker` (`[empty: 上游空补全，已重试1次]`) as an assistant message (`MessageStart`…`MessageEnd` + `appendMessage`, `finish="stop"`) and continue; assistant-tail history → loop appends AutoContinue's `continue`; `emptyPlaceholderHardStop=2` consecutive → 「连续空补全占位 N 次」; real output resets.
- **Lesson**: a guard justified by "invalid on the wire" is fixed by a valid message, not retries or fatal errors; check synthesized turns against the next request's tail invariant.
