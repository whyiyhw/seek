### Exhausted empty retries must be booked as a message — a bare assistant tail is a 400, not a self-heal
- **Saw**: on the `opencode:deepseek-v4.1-flash` lane (11-20 evening) `agent: model returned an empty response` fired 8+ times; each one ended the *whole session* mid-task — `/tmp/seek-acp.log` went silent for 51 lines with zero events, and a working ACP conversation was dead with its context unrecoverable. One clean retry is already in `Prompt`, so the budget was simply too small for a lane that empties repeatedly
- **Why**: the retry budget (`agentStreamRetries=1`) was the only recovery, and its exhaustion branch was `ErrorEvent + return`. But the retry loop's own doctrine already says a clean empty emitted NOTHING to the UI — so there is nothing to duplicate per attempt, and nothing that forces the turn to die. The only real constraint is the wire contract: an assistant message with neither content nor tool_calls is rejected by DeepSeek ("content or tool_calls must be set"), which is *why* the empty was uncommittable in the first place. Give the turn a non-empty assistant content and the objection disappears
- **Fix**: on `errEmptyResponse` with the budget spent, synthesize `emptyResponseMarker` (`[empty: 上游空补全，已重试1次]`) as a real assistant message — `MessageStart`/`MessageDelta`/`MessageEnd` + `appendMessage`, `finish="stop"`, no error — and continue the turn loop (`pkg/agent/agent.go`). Because history now ENDS with assistant, the loop appends the same `continue` user message AutoContinue uses (DeepSeek 400s on an assistant tail without beta prefix mode). Streak gate: `emptyPlaceholderHardStop=2` CONSECUTIVE placeholder turns → error 「连续空补全占位 N 次」, reset on any turn with real output. reasoning-only-empty and `finish=length` branches untouched
- **Lesson**: when a guard's whole justification is "this message shape is invalid on the wire", the fix for exhausting it is a *valid message*, not a bigger retry budget or a fatal error. And whenever you synthesize an assistant turn, check what it does to the *next* request's tail invariant — the marker made history legal and simultaneously made the following request illegal
