### A hand-built empty error carries the sentinel's TEXT but not its identity — the self-heal gate can never match it
- **Saw**: `opencode:deepseek-v4.1-flash` sessions died with `agent: model returned an empty response (no content and no tool calls)` — 8+ on 11-20, 2 on 11-24, c_trrsn7 on 11-25 (`/tmp/seek-acp.log`).
- **Why**: `streamDelta` lacks `reasoning_content` (zero events, `started` false); 2nd-tier budget is `a.cfg.MaxTokens`, not `a.turnMaxTokens()` → hidden thinking burned all 16384 (`finish_reason="length"`); that path hit inline `errors.New` (sentinel text, not identity) — `errors.Is(err, errEmptyResponse)` never matched, `ErrorEvent` ended the session (c_jdel6u/c_7kco3z/c_geyjoo skipped).
- **Fix**: `errBudgetExhaustedEmpty` sentinel (not retryable, not `errEmptyResponse`) + `budgetExhaustedMarker` (`[empty: 上游结束原因非 stop 且零内容…，未重试]`), both into `Prompt`'s gate; also: `runTurnLLM` now calls `isSafetyRefusal` (`refusal` was booked as empty), openai assembler keeps tool calls past index holes.
- **Lesson**: a value recovered via `errors.Is` must be constructed in one place — never inline `errors.New` in a sentinel-covered branch; a lane that can't parse all upstream output must treat empty-with-odd-finish as normal, not fatal.
