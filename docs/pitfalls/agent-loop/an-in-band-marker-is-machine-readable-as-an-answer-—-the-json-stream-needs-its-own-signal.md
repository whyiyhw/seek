### An in-band marker is machine-readable as an ANSWER — the JSON stream needs its own signal
- **Saw**: `seek -p --json` on an empty upstream (reasoning ate the whole `--max-tokens`) exited **0** and the only content-bearing line was a `text_delta` carrying the Chinese marker `[empty: 上游空补全，已重试1次]`. A program consumer that concatenates non-reasoning deltas — the documented way to get the reply, and what `eval/run.sh` / `internal/controlplane` do — reported the marker as the model's answer
- **Why**: the self-heal (card c_jdel6u) deliberately books the marker as real assistant *content* so history stays a legal continuation, and the TUI commits deltas, so the marker must stream as a `text_delta`. Both consumers are correct; the defect was that the JSON contract carried NO other trace of "this turn produced nothing" — the turn `finish_reason` was `stop`, identical to a real answer
- **Fix**: per-turn classification on the event, not prose matching. `TurnEnd.Finish` + `jsonLine.finish_reason` (additive, `omitempty`) report `agent.FinishEmptyResponse` (`"empty_response"`) for a placeholder turn; `AgentEnd.Finish` deliberately keeps the upstream vocabulary so the ACP stopReason mapping and hooks' `PostTurn` contract are unchanged. Documented in `docs/guide-commands.md` § "`--json` event-stream contract"
- **Lesson**: a human-readable in-band marker is only human-readable if the machine channel also says what happened. Any self-heal that turns "nothing" into "some bytes" owes the structured channel a typed field for the same fact — otherwise every consumer re-implements a Chinese string prefix
- **Refs**: `pkg/agent/events.go` (`FinishEmptyResponse`), `pkg/agent/agent.go` (`placeholderTurn` → `TurnEnd.Finish`), `cmd/seek/main.go` (`jsonLine.FinishReason`), `cmd/seek/json_empty_test.go`, cards c_jdel6u, c_jxwsfz
