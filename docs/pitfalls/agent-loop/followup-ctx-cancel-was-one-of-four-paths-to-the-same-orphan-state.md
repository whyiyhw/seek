### Followup: ctx-cancel was one of FOUR paths to the same orphan state
- **Saw**: the original 986a485 fix covered only user-cancel; boundary stress tests found three more routes: server hangs up without `[DONE]`, SSE chunk fails JSON decode, server emits `finish_reason="stop"` alongside `tool_calls` (possible through proxies).
- **Why**: the invariant is the `tool_calls ↔ finish_reason` coupling, not "ctx was cancelled" — any path returning from `runTurn` with `len(ToolCalls)>0 && finish != "tool_calls"` is corrupt; the original fix removed one cause.
- **Fix**: explicit invariant check in `Prompt` between `runTurn` and the append: refuse a turn whose tool_calls don't match its finish_reason, emit `ErrorEvent` instead (commit `d022ee0`).
- **Lesson**: when the symptom is a state-shape violation, test the SHAPE ("any path producing tool_calls without finish=tool_calls → history broken"), not the cause ("pressed Esc") — the shape test catches regressions the cause-shaped one misses.
