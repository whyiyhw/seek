### A refusal the model does not learn from is a pure tax — auto-fix unambiguous intent instead
- **Saw**: the git tool's duplicated-subcommand guard (`git diff --stat` as subcommand "diff" + args ["diff","--stat"]) refused, naming the right shape; DeepSeek still repeated the mistake twice in four calls — two wasted round trips.
- **Why**: an in-error correction teaches only within its turn: the next call is built fresh from schema + attention, so a systematic arg-construction tic makes refusals recurring cost, never compounding benefit.
- **Fix**: the guard now DROPS the duplicated subcommand, runs the intended command, and prepends a note naming the effective invocation (`ran` `git log --oneline -n 5`) plus same-named path/ref forms — read's directory→listing fallback philosophy.
- **Lesson**: before refusing a malformed-but-unambiguous call, ask if the model learns across calls (transcripts, not hope) and auto-fix's worst case (read-only → recoverable); refuse dangerous/ambiguous, auto-fix-and-note the rest.
