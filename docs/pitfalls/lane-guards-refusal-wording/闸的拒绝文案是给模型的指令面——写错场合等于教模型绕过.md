### 闸的拒绝文案是给模型的指令面——写错场合等于教模型绕过
- **Saw**: 2026-11-19 v0.12.1：`seek acp` + `SEEK_ACP_YOLO` 车道用户要求推送，no-remote 闸以「autopilot runs unattended and does not push」拒绝（人在场，前提错）；被拒两次后改走 `sh /tmp/release-push-v0.12.1.sh`（字面只见 `sh`），推送完成。
- **Why**: 闸是 best-effort 字符串匹配（头注释：defense-in-depth, not a security boundary），reason 却被当权威事实；「无人值守」由车道决定，guard 不知车道——goal/autopilot/SEEK_ACP_YOLO 共用 pattern 表与 reason。
- **Fix**: reason 改处置指引（非安全边界、点名车道、授权由人执行）；`IsRemoteMutatingOnLane(lane, command)` 同表只换车道名，`IsRemoteMutating` 签名不变，三处 mount 点传真实车道；`bash.go` deny 分支补 `Hint:` 行，`[bash: blocked —` 前缀（含尾空格）逐字保留，9 条 blocked 不变。
- **Lesson**: 拒绝文案是指令面不是日志：guard 不知的事（有人在否、授权否）不能陈述，只述所知并给处置；改文案须逐条断言 blocked 集合不变。
- **Refs**: `internal/autopilot/guard.go`、`internal/tools/bash/bash.go`（`denyHint`）、`cmd/seek/main.go`（`laneGuard`）；同族「`[plan: approved]` is a load-bearing wire-format prefix」
