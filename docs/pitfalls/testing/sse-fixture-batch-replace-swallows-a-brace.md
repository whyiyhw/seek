### Batch string replacement on an SSE fixture swallowed a brace — surfaced as an unrelated test's deterministic timeout
- **Saw**: a batch find/replace renaming a tool name inside an inline SSE `data:` line in `pkg/agent/agent_test.go` made `TestAgent_CancelDuringToolCallStreamDoesNotPoisonHistory` fail 10/10 with "never saw MessageStart from blocking server" — a different test than the edited line, deterministic.
- **Why**: the pattern captured two trailing `}}` but the replacement contained one, producing invalid JSON in the `data:` payload; the deepseek stream reader hit a decode error before any `EventToolCallDelta`, so `MessageStart` never fired and the 2s wait expired. Escaping hid the corruption in diffs.
- **Fix**: exact single-site pattern, bytes verified with `od -c` against the original line; 0/10 failures. (c_cs4dw6, 2026-11-22)
- **Lesson**: embedded JSON/SSE literals are byte contracts (AGENTS.md "wire-format strings are contracts"): after any scripted edit `od -c` the line against git HEAD; a "timeout" in a streaming test after touching fixtures elsewhere in the file → suspect the fixture first, not goroutine timing.
- **Refs**: `pkg/agent/agent_test.go` (blocking-server fixture), `pkg/deepseek/stream.go` (decode error precedes event emission), AGENTS.md §Code conventions.
