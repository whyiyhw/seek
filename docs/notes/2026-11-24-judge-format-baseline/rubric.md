# 判据：邮件

## 我要留的
- 等我回复、等我决策、等我填表：这封信的下一步动作在我身上
- 漏了会疼：账单、到期提醒、账号安全、CI 失败、老板/家人/客户来信
- 带具体事实且与我正在做的事相关（数字、日期、可复现步骤、对某个具体决定的反对）

## 我要丢的
- 营销、促销、产品更新公告、newsletter
- 纯通知且无需我动手：完成回执、自动对账成功、订阅确认
- 纯情绪表达或转述转发，没有新增信息

## 灰区（必须人看，永不自动处置）
- 不确定是不是群发
- 涉及钱或法律但我没有足够上下文判断
- 发件人陌生但内容像是找我办事

## 输出
只输出一个 JSON 对象，不要 markdown 代码块，不要任何解释文字：
{"verdict":"keep|drop|gray","reasons":["短句","短句"]}
