Budget — Context Window Limits

Budget — 上下文窗口预算

Model context window limits and early warnings before hitting the cap.

在接近模型限制时提前给出警告，避免 token 超限中断。

Warnings

预算警告

The TUI status bar shows usage warnings before hitting the limit:

TUI 状态栏显示使用量警告：

  • Amber — usage > 60% (WarnFraction = 0.60)
  • 琥珀色 (amber)——使用量超过 60%（WarnFraction = 0.60）
  • Red + /compact soon — usage > 75% (CriticalFraction = 0.75)
  • 红色 + /compact soon 提示——使用量超过 75%（CriticalFraction = 0.75）

Warnings are passive (no popup, no picker). The TUI status bar (top-right) shows:

警告不打断对话，TUI 右上角显示：

ctx 42%          # safe zone — muted grey
⚠ ctx 63%        # > 60% — amber warning
⚠ ctx 77% — /compact soon  # > 75% — red bold

What Happens at the Limit

达到限制后的行为

  • seek does NOT silently truncate history (would break prefix cache)
  • seek 不会静默截断历史（截断会破坏前缀缓存）
  • Recommended: use session /branch (fork) or /compact to reduce context
  • 建议：使用会话管理功能（/branch 分叉 / /compact 压缩）缩小上下文
  • Or use --resume in a new session, keeping the old one as reference
  • 或使用 --resume 在新会话中继续

See Session Management for context reduction strategies.

参见会话管理了解如何缩减上下文。

Design Notes

设计要点

  • Static over auto-detection — stale table under-reporting capacity is safer than runtime TTY probes
  • 硬编码优于自动探测——过时的表安全地少报容量，远好于运行时 TTY 探测问题
  • Passive budget — warns only, no active budget management by the agent
  • 被动预算——仅警告，不由 agent 主动管理
  • Token usage from API — budget data comes from the LLM API's usage field, not local estimation
  • 预算来自 API——基于 LLM API 返回的 token 使用量，非本地估算
