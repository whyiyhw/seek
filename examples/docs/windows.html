Windows — Terminal & TUI Guide

Windows — 终端与 TUI 指南

Best experience inside Windows Terminal. PowerShell or CMD both work.

推荐使用 Windows Terminal 运行 seek。

Install Windows Terminal

安装 Windows Terminal

$ winget install --id Microsoft.WindowsTerminal -e  # Recommended

Also available via Microsoft Store or GitHub Releases.

也可通过 Microsoft Store 或 GitHub Releases 下载。

Usage

使用方法

  1. Open Windows Terminal (search "Terminal" in Start menu)
  2. 打开 Windows Terminal（开始菜单搜索 Terminal）
  3. Open PowerShell or CMD tab
  4. 新建 PowerShell 或 CMD 标签页
  5. Run seek — first launch walks through API key setup
  6. 运行 seek，首次运行会引导设置 API Key

Multi-Line Paste

多行粘贴

Windows Terminal supports multi-line paste by default. Raw conhost.exe (CMD/PowerShell outside WT) does NOT — each line is treated as a separate command. Use Windows Terminal to paste multi-line code blocks.

Windows Terminal 默认支持多行粘贴。原始终端（conhost.exe）不支持——每行会被当作单独命令。使用 Windows Terminal 粘贴多行代码块。

Path Setup

添加到 PATH

First run shows an "add to PATH?" prompt. Can also run manually:

首次运行显示"添加到 PATH"提示，也可以手动执行：

$ seek --install

Known Limitations

已知限制

  • No sandbox — Windows is not a supported sandbox platform. Degrades to worktree-level isolation.
  • 无沙箱——Windows 不支持内核沙箱，降级为 worktree 逻辑隔离。
  • OCR disabled by default — needs ocr.command to be configured.
  • OCR 默认关闭——需要配置 ocr.command。
