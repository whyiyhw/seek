Push Notifications via Webhooks

推送通知 — Webhook 桥

Push cron completions, autopilot results, and long-turn notifications to your phone.

将 cron 任务完成、autopilot 结果、长时间交互回合通知推送到你的手机。

Configuration

配置方法

Edit ~/.seek/config.json (create if not exists):

编辑 ~/.seek/config.json：

{
  "push_webhooks": [
    { "url": "https://ntfy.sh/your-topic",  "format": "ntfy" },
    { "url": "https://hooks.slack.com/...",  "format": "slack" },
    { "url": "https://discord.com/api/...", "format": "discord" }
  ]
}

Per-webhook options

配置项详解

Field字段Type类型Description说明
urlstringWebhook endpoint URLWebhook 地址
formatstringFormat name from table above上述格式名
events[string]Subscribe to specific events (default: all)订阅特定事件（默认全部）
devices[string]Target device IDs for push目标设备 ID

Event types

事件类型

  • cron.completed — a scheduled job finished
  • cron.completed——定时任务完成
  • goal.completed — a goal run finished (met/capped/stalled/error)
  • goal.completed——goal 运行结束
  • session.completed — an interactive TUI turn that ran over session_notify_seconds
  • session.completed——交互回合持续超过 session_notify_seconds

Global relevant config

全局相关配置

{
  "session_notify_seconds": 60  // Default 60s. 0 = disable session push.
}
